# 👑 Fashion Code — Prototype Web de Luxe

> "Révélez la meilleure version de vous-même."

Ce dépôt contient le prototype ultra-premium, entièrement responsive et interactif du site web de **Fashion Code**, salon de beauté d'exception à Parakou. Inspiré des codes visuels des plus grandes maisons de luxe (Dior Beauty, Chanel, Fenty) et des salons prestigieux de Dubaï.

---

## ✨ Points Clés du Design & de l'Expérience

*   **Identité Visuelle Forte :** Palette de couleurs minimaliste et prestigieuse (Noir profond `#090909`, Doré métallique `#D4AF37`, Blanc cassé).
*   **Technologie "Glassmorphism" :** Des interfaces modernes en transparence vitrée avec flou d'arrière-plan.
*   **Comparateur Avant/Après Interactif :** Un module fluide permettant d'apprécier la transformation des clientes en temps réel.
*   **Concept de Réservation Premium :** Une interface UI/UX intuitive guidant l'utilisatrice à travers le choix de sa prestation, de son experte et de son horaire.
*   **Performance & Fluidité :** Animations d'apparition ("Reveal") optimisées et sans dépendances lourdes pour garantir un chargement instantané.

---

## 🛠️ Stack Technique

Afin de garantir une portabilité maximale pour la phase de présentation client, le prototype a été conçu dans **un unique fichier autonome** :

*   **HTML5** : Structure sémantique de haute qualité.
*   **CSS3 (Custom)** : Design système complet, variables CSS, effets de lueur et responsive grid.
*   **JavaScript (ES6+)** : Logique de filtrage dynamique de la galerie, gestion du slider comparatif, système de modale (lightbox) et animations au défilement.
*   **Typographies** : *Playfair Display* (Sérif de luxe) & *Poppins* (Sans-Sérif géométrique moderne) via Google Fonts.
*   **Icônes** : *Bootstrap Icons* pour une finesse visuelle optimale.

---

## 🚀 Comment Lancer le Prototype ?

Aucune installation complexe (ni Node, ni serveurs) n'est requise pour cette phase de validation :

1.  Téléchargez ou clonez ce dépôt.
2.  Double-cliquez sur le fichier `index.html`.
3.  Le site s'ouvre instantanément dans votre navigateur préféré (Chrome, Safari, Firefox).

*Note : Pour une expérience optimale sur mobile, vous pouvez héberger ce fichier gratuitement sur GitHub Pages ou Vercel en moins de 2 minutes.*
